# 패턴 카탈로그 — 승인 구조 29종

[base-template.html](../assets/base-template.html)은 제작용 중립 예제 모음이다. 실제 강의 대본·제품명·작업 캡처를 넣지 않는다. **기존 9종 유지 + 현재 승인본에서 20종 추가**. 같은 모양의 이름만 바꾼 변형은 별도 패턴으로 세지 않았다.

## 고르는 순서

1. [골든셋](goldenset-approved-course.md)의 방식으로 이 장이 증명할 관계를 정한다.
2. 아래 표에서 그 관계와 맞는 패턴을 고른다. 제목 단어만으로 고르지 않는다.
3. 원본을 참고할 때 현재 승인 HTML을 본다. 원본의 문장은 복사하지 않는다.

## 복사 단위와 실행 계약

- `article[data-pattern="..."]`이 화면 단위다. 베이스 전체를 복사한 다음 필요한 article만 남기는 것이 가장 간단하다.
- 원래 1~9번은 `scene`, `triptych`, `structure-tree`, `exchange`, `transition-compare`, `scope-panel` CSS를 쓴다. 새 10~29번은 **공통 `tx-*` CSS**와 토큰을 공유한다. 사용하지 않는 예제 article은 남기지 않는다.
- 상단 `svg.symbols > defs`의 `shape-*`와 `tx-arrowhead`를 사용한다. 필요한 도형을 삭제하면 빈 그림이 된다.
- `data-slot`은 교체할 의미 위치다. 요청문·캡션·그림 안의 이름도 모두 새 스토리보드에 맞춘다. 범위 밖 고유명사가 남았는지 검사한다.
- 16~18, 20~21, 24, 26~27은 `.tx-graph` 연결 엔진을 쓴다. `data-node` ID와 `data-from/to`를 맞춘다. 노드의 CSS `--x/--y`는 레이아웃 좌표이며 선 끝점은 **실제 아이콘의 화면 좌표**에서 계산한다.
- `drawPatternConnections`, `ResizeObserver`, `document.fonts.ready`를 유지한다. 폰트 로드·창 크기 변경 후에도 선이 따라간다. `<path>`만 캡처해 고정 좌표로 다시 붙이지 않는다.
- `data-anim-step`이 순서를 정한다. 같은 단계는 함께 나타난다. 부모 전체가 한 번에 등장하는 것과 자식의 순차 등장을 중첩하지 않는다.
- `.scope-frame`은 경계만 표시한다. 부모의 실선은 투명하고 실제 경계가 별도 등장한다. 경계가 개념에 필요 없으면 프레임과 범위 자체를 함께 제거한다.
- 문구의 크기는 `--title / --statement / --heading / --body` 역할 토큰을 우선한다. 임의의 단일 장 축소보다 문구·폭·간격을 먼저 고친다.
- 템플릿은 슬롯이 짧은 예시다. 실제 문구로 채운 후 다시 검수해야 한다. 통과한 빈 템플릿은 긴 문장까지 보증하지 않는다.

### 12 — 단계별 강조

`data-focus="1"`을 `2`, `3`으로 바꾼 연속 장을 복제한다. 해당 단계의 제목·하단 설명도 맞춘다. 지도 위치는 동일하게 유지한다. 정지 구성이 필요하면 `data-motion="none"`을 유지한다. 단계의 위치(영역), 그곳에서 하는 일(행위), 파일의 조건(상태)은 별도 의미다.

### 19 — 클릭 전환

`data-panel`과 `data-panel-view` 값이 대응한다. `.active`와 `aria-selected`는 `selectPatternPanel`이 함께 갱신한다. 클릭/Enter/Space/탭 방향키가 패널을 선택하며 덱을 넘기지 않는다. 진입 시 `data-default-panel`로 돌아가고, 자동 타이머는 없다. 숨긴 패널은 접근성 트리·포커스에서 제외한다.

### 22 — 메시지 방향

예제는 왼쪽 조율 역할 / 오른쪽 실행 역할. 질문과 보고는 왼쪽, 응답은 오른쪽이다. 주체를 바꾸면 `.tx-arrow--back`을 **발신자 기준**으로 함께 갱신한다. 실제 프로토콜의 모든 메시지가 이 세 방향으로 제한된다는 뜻은 아니다.

### 23 — 목표와 완료 기준

입력·결과물·완료 기준이 요청문에도 실제로 있어야 한다. 슬롯의 ‘확인할 조건’은 배포 문구가 아니다. 실제 내용에서는 **사실 일치·산출물 수·제출 형태처럼 확인 가능한 조건**으로 바꾼다. 회사 말투 같은 스타일도 구체적인 규칙을 제공하면 기준이 될 수 있다.

### 29 — 클릭 이동

슬라이드 진입은 시간선·라벨·차량의 등장만 실행한다. 이동은 해당 차량을 활성화할 때 시작하고 첫 키프레임부터 반응한다. 클릭 시 반복 재생, 재진입 시 출발 위치로 복구. 모션 감소에서는 클릭 후 최종 위치로 전환한다. 이 비유는 한 번에 한 위치라는 성질을 설명할 때만 쓴다.
