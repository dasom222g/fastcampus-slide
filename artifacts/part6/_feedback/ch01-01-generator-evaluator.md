## 2026-10-06 — 3~9장 의미·시각 재검수

- 상태: 수정·자체 검수 완료, 사용자 최종 승인 대기. 1~2장은 이번 수정 전 HTML 그대로 보존.

- 3장 **작성과 평가의 분리**: 장문 패널을 Worker A → 초안·수정본 → Worker B와 피드백 반환 점선으로 교체.
- 4장 **다른 모델로 평가하는 이유**: 이유/하네스/주의사항 3열을 같은 모델 A→A / 다른 모델 A→B 비교로 교체. 효과를 보장하거나 하네스를 모델처럼 부르지 않음.
- 5장 **고정된 평가 기준**: 순서로 읽히던 규칙 나열을 체크리스트 → 평가 워커로 교체. 비공개는 이 실습의 규칙으로 한정.
- 6장 **근거가 남는 평가**: 임의 C번호·판정 예시 제거. 항목/결과/근거/위치 기록과 원문 대조·스크립트 검산 표현. 이전 일괄 치환으로 생긴 ‘평가은’도 제거.
- 7장 **반려는 사유와 함께**: 평가 워커 → 수정 요청서 → 작성 워커. 요청서에 반려 항목·위치/근거/고칠 내용.
- 8장 **수정과 재평가 루프**: 같은 작성 워커로 반환, 전 항목 Y·독립 검산 완료 시 최종본. 실제 프롬프트의 최대3라운드·미해결 보고 종료 반영.
- 9장 **영업팀에 적용**: 제안서·견적서와 교차 검토 보고서를 문서로 표현. 다음 영상 안내를 학습 목록에 섞지 않음.
- 디자인: 승인 로봇·문서 문법, 역할별 공통 타이포, A brand/B purple 일관성, CSS 배치·DOM 실측 연결, 반환 곡선과 라벨 동시 페이드.
- 검수: 1920×1080·1280×800 전9장 캡처와 DOM 경계 검사 통과. 이미지 누락 없음. 본문 클릭 유지, 버튼·점·방향키·Space 이동, 진입/중간/완료/재진입 및 반환선 좌표 고정 확인. 브라우저 오류 없음.
- 증거: `_qa/generator-evaluator-review/`의 layout-results.json, interaction-results.json, animation-frames.json, 캡처.
- 대본: 코디네이터는 변경하지 않음. 사용자의 별도 요청으로 Claude Code 새 세션에 HTML 직접 파악 + fastcampus-script 스킬·골든셋 필수 확인 후 작성만 요청. 초안·장별 해석은 전달하지 않음.
