## 슬라이드 5 / 5 — Git과 GitHub

타입: 기존 git-github 카드 비교. 사용자 선택에 따라 크기·배치·테두리·도식 유지.
부제: Git은 버전 관리 시스템이고, GitHub는 Git 저장소 호스팅 서비스입니다.
왼쪽: 노트북 도식 → Git → 버전 관리 시스템 → 파일의 변경 이력을 / 기록하고 관리합니다.
오른쪽: 구름 도식 → GitHub → Git 저장소 호스팅 서비스 → 프로젝트와 기록을 / 온라인에 보관하고 공유합니다.
역할 명칭은 전문용어로 구분하고, 아래 두 줄은 쉬운 말로 설명한다. 두 카드 모두 기존 display/name/body-copy 규격을 사용하며 폰트를 줄이지 않는다.
애니메이션: 왼쪽 카드 → 오른쪽 카드.
정확성 근거: GitHub 공식 문서의 GitHub and Git 절. Git은 version control system, GitHub는 Git 저장소를 온라인에 호스팅하는 서비스.
https://docs.github.com/en/get-started/start-your-journey/what-is-github
