## 슬라이드 1 / 1 — 화면의 세 덩어리

- **타입:** CARD_GRID — `grid-3` + `media-card` + `.ui-map` SVG
- **핵심 메시지:** 처음 켠 화면은 왼쪽·가운데·오른쪽 세 덩어리로 나뉜다
- **근거:** 소스 「1. 화면은 세 덩어리다」 — "**왼쪽** — 작업 공간 목록. 지금 무엇들이 돌고 있는지", "**가운데** — 선택한 작업의 내용과 에이전트 터미널", "**오른쪽/아래** — 변경된 파일과 결과 검토"

**화면 요소**

| 요소 | 내용 |
|---|---|
| slide__label | Section 1 · Screen Layout |
| slide__title | 화면의 **세 덩어리** |
| slide__sub | 처음 켠 화면은 왼쪽·가운데·오른쪽 세 덩어리로 나뉜다 |
| 카드 1 (gray) | `.ui-map` 왼쪽 칸 켜짐 / 🗂️ / `왼쪽` / 지금 무엇들이 돌고 있는지 보여주는 작업 공간 목록 |
| 카드 2 (brand) | `.ui-map` 가운데 칸 켜짐 / ⚙️ / `가운데` / 선택한 작업의 내용과 에이전트 터미널 |
| 카드 3 (green) | `.ui-map` 오른쪽 칸 켜짐 / 📄 / `오른쪽·아래` / 에이전트가 바꾼 파일과 결과 검토 |
| tip | 이름을 외우기 전에 세 덩어리의 자리부터 익힌다 (`출처 없음 — 연결용`) |

> 세 카드는 **같은 창 그림**을 쓰고 켜진 칸만 다르다. 뿌리와 잎만 바뀌게 두면 위치 차이가 말 없이 읽힌다.
> 카드 색이 곧 그 자리의 역할이다 — 목록은 gray, 에이전트가 도는 곳은 brand, 결과물은 green.

**애니메이션 순서**
1. 카드 1 (왼쪽)
2. 카드 2 (가운데)
3. 카드 3 (오른쪽·아래)
4. tip

**발표 노트**
> 설치를 마치고 처음 켜면 화면에 요소가 많아 보입니다. 이름부터 외우려 하지 말고 덩어리 세 개로 나눠서 보세요. 왼쪽은 지금 무엇들이 돌고 있는지를 보여주는 목록, 가운데는 그중 하나를 골랐을 때 그 작업의 내용과 에이전트 터미널, 오른쪽과 아래는 에이전트가 바꾼 파일과 결과를 검토하는 자리입니다. 실제 화면은 이어서 함께 보겠습니다.
