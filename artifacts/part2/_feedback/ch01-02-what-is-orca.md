## 2026-09-08 — 4번 슬라이드 작업 단위 명확화

- 사용자 요청: 핵심은 Orca의 기본 작업 단위가 워크트리라는 것. Git 파트에 앞서 폴더라는 구체적인 의미를 간단히 설명하고 혼동을 줄인다.

- 다음부터: 입문 개념은 ‘도구에서 맡는 역할 → 일상적인 실체 → 그 안에서 하는 일’로 설명한다. 익숙하지 않은 개념을 다른 낯선 개념 목록으로 정의하지 않는다.
