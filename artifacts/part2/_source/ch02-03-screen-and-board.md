# Ch02-03. 화면 구조와 보드 읽는 법

제작 목표: 처음 켠 화면의 왼쪽·가운데·오른쪽 세 영역을 도식으로 설명한다

2026-09-09 사용자 요청으로 「화면의 세 덩어리」 한 장만 남기고 인덱스 목록에서 제외한다.

> **이 클립은 화면을 가르친다.** 화면에 실제로 보이는 이름을 그대로 쓴다. 임의로 바꾸지 않는다.
> 실제 화면 캡처는 영상에서 보여주므로, 슬라이드는 **화면의 구조(어디에 무엇이 있는가)**를 도식으로 다룬다.

#### 1. 화면은 세 덩어리다

역할: 처음 켠 사람이 길을 잃지 않게 큰 덩어리부터 나눈다.

말할 내용

- **왼쪽** — 작업 공간 목록. 지금 무엇들이 돌고 있는지
- **가운데** — 선택한 작업의 내용과 에이전트 터미널
- **오른쪽/아래** — 변경된 파일과 결과 검토

슬라이드: 1장 — 3분할 도식
