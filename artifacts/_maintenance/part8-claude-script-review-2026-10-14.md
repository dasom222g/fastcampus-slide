## Ch01-01 흐름 — 소개 → 결과물 → 패턴 → 채널 기준 → 소재 준비 → 선정 관점 → 자료 범위 → 전체 구조

- 1~3장은 골든셋 74 틀을 따랐다. 표지는 「네 번째 프로젝트인 콘텐츠팀의 구조」로 열고 앞 세 팀을 한 구절씩 대비(81), 사람이 정할 것/에이전트가 할 것으로 닫았다.
- 2장: 결과물 3종 → 누구에게 맞는 프로젝트 → 그냥 시키면 안 되는 이유 → 형태별 결과 → 실습 진행 한 줄. 링크가 없으므로 「한번 볼게요」류 동작을 넣지 않았다. 딸기 디저트는 예시라고만 말하고 문구는 읽지 않았다. 파일명(blog.md) 대신 「이미지와 태그까지 들어간 글」.
- 3장: R&R 풀이 → 디자인팀(하나 고르기)과 대비해 결과를 모두 사용 → 제일 중요한 것 = 역할과 책임을 분명히 나누는 것 + 이유.
- 4장: 사람이 채널의 독자·말투·전략과 소재 브리프 작성 기준을 정하고 확인. 화면 4장에 없는 콘텐츠 포맷은 넣지 않았다. 소재 브리프를 처음 말하는 자리에서 풀었다(79). 에이전트가 할 수 있는 제안을 먼저 인정하고 사람이 확인하는 이유를 붙였다(81).
- 5장: 소재 수집 워커가 후보·출처 수집 → 소재 선정 → 브리프 작성 → 보고. 코디네이터는 확인·전달만 하며, 기획팀과 마찬가지로 코디네이터를 거친다(79). 지정 소재는 수집 워커 없이 오케스트레이션 전에 브리프를 먼저 준비.
- 6장: 독자 가치·채널 적합성·출처 신뢰성 각각에 「그래서 뭐가 문제냐」를 붙였다. 출처 신뢰성은 같은 사실로 모든 플랫폼을 만든다는 이 팀의 사실로 이유를 댔다. 「판단의 관점이지 고정 평가표가 아니다」로 범위를 열었다.
- 7장: 공통(채널 기준·소재 브리프) / 담당(콘텐츠 포맷과 고른 포맷의 샘플)을 자료 범위로 구분. 공통 문서 동봉을 기획팀의 공통 지침·사업 조건과 연결했다(맥락 붕괴 대응, 79의 「마찬가지로」 방식). 포맷 선택 방법은 Chapter 3으로 미뤘다.
- 8장: 「콘텐츠팀도 오케스트레이션 스킬로 돌릴 건데요」(79·81). 코디네이터 = 브리프 확인·전달·제작 배정, 소재를 고르거나 브리프를 쓰지 않음(55). 모델 배치는 강사의 설계 선택으로 표시(78·79). 하위 워커는 실습자료 용어표의 정의로 그 자리에서 풀었다. 사람 = 채널 기준·포맷 확정 + 결과 확인. 게시 판단·근거 점수는 넣지 않았다. 「알아서 돌아가지 않는다」로 강의 축을 짚고 다음 영상(Ch01-02 스킬 팩 설치)으로 넘겼다.

## Ch03-01 흐름 — 소개 → 한 대화의 문제 → 플랫폼 차이 → 역할 분리 → 공통/표현 → 포맷 선택

- 1장 표지: 앞 영상(채널 기준·브리프 작성 기준) 회수 → 「그전에 짚고 갈게요」(82) → 화면 부제를 한 줄 논지로. 2장의 원인(긴 대화)은 표지에 꺼내지 않았다.
- 2장: 결론 → 짧은 글 하나는 괜찮다고 먼저 인정(81) → 서로 다른 작성 방식 + 쌓이는 수정 요청을 함께 원인으로 → 「놓치기 쉽다·~수 있어요」로 단정 회피 → 사람이 하나하나 다시 확인해야 한다는 손해로 닫음. 수정 요청 하나만 탓하지 않았다.
- 3장: 플랫폼별 전달·소통 방식. 레시피가 아닌 가을 단풍 여행지 예시를 이 영상 안에서 돌려 썼다(5장 입장료 예시로 이어짐).
- 4장: 핵심 = 담당 플랫폼에 맞는 콘텐츠 제작에 집중. 2장 원인을 회수(76·77)하고, 포맷·샘플은 부수 정보로만 말했다. Ch01-01의 R&R 분배와 연결.
- 5장: 같이 지킬 것(채널 독자·말투·전략, 핵심 사실·출처 링크, 회차 목적·핵심 메시지, 피할 표현) / 바꿀 것(전개·첫 문장·분량·이미지·캡션·태그). Ch01-01 7장의 자료 목록과 겹치지 않게 「무엇이 같아야 하고 무엇이 달라지나」로 썼다. 장 경계 문장으로 6장을 불렀다.
- 6장: AGENTS.md 「포맷 선택 기준」과 대조 — 브리프의 콘텐츠 유형·목적·대상 독자·핵심 메시지 ↔ 포맷별 용도, 하나 선택, 연결된 샘플만 읽고 구성·표현만 참고, 포맷 공통 작성 조건 준수, 고른 포맷과 이유를 원고에 기록. 기록 이유와 「포맷 목록과 용도는 우리가 정한다」는 주장 문장을 넣고 다음 영상(Ch03-02 블로그 포맷)으로 넘겼다. 특정 포맷 이름은 고정하지 않았다.
