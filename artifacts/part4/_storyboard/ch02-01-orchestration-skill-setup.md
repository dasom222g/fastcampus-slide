# 오케스트레이션 스킬 설치하기 — 도입 스토리보드

총 1장. Part 1에서 이동한 대비 슬라이드이며 설치 실습의 도입으로 사용한다.

## 슬라이드 1 / 1 — 일을 나누고, 넘기는 흐름까지

- 타입: 기존 2단 대비. 설치 실습 앞에 삽입하는 한 장이므로 별도 표지를 추가하지 않는다.
- 왼쪽 사람·문서 전달 도식과 멀티 에이전트 과도기 설명 유지.
- 오른쪽 Orca 로고를 에이전트 간 결과 전달·반환 경로 도식으로 교체.
- 오른쪽 제목은 확정 명칭 “에이전트 오케스트레이션의 시대”를 온전히 쓴다.
- 하단에 별도 도구 영역을 만들지 않는다.

발표 대본:

에이전트를 여러 명 써도 자료를 받아 다음 담당자에게 넘기는 일을 사람이 계속 맡으면 멀티 에이전트 과도기에 머물게 됩니다. 조사 결과를 작성 담당에게, 초안을 검토 담당에게, 검토 의견을 다시 작성 담당에게 내가 옮기는 거죠.

오른쪽은 그 연결을 협업 흐름으로 만든 모습입니다. 목표를 받으면 누가 어떤 일을 하고, 어떤 결과를 다음 담당자에게 넘기고, 문제가 나면 누구에게 돌려줄지를 정해 둡니다. 그 순서에 따라 에이전트가 일을 나누고 이어서 수행하는 겁니다.

이것이 에이전트 오케스트레이션의 시대에서 달라지는 지점입니다. 에이전트의 수만 늘리는 것에서, 서로 일을 주고받는 흐름까지 구성하는 것으로 넘어가는 거예요.

이제 이 흐름을 구성하고 운영할 때 사용할 오케스트레이션 스킬을 설치해 보겠습니다. 설치한 뒤에는 목표 하나를 주고, 일이 어떻게 나뉘고 다음 담당자에게 이어지는지 확인할 겁니다.
