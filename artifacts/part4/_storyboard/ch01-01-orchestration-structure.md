**구조·색:** 폴더 경계 안에 세 에이전트를 모두 배치한다. 왼쪽 위·아래 Worker A(brand)와 B(purple), 오른쪽 중앙 Coordinator(yellow). 각 워커 옆에 작업 파일을 표시한다. 코디네이터 아이콘 중심을 두 워커 아이콘의 중간 높이에 두고 실제 위치를 측정해 두 보고 곡선을 대칭으로 연결한다. 폴더의 은은한 회색 외곽과 선명한 에이전트·연결선으로 작업 공간과 소통 관계를 구별한다.

**간격:** 최대 너비 56rem, 화면 너비의 76% 이내. 열 비율 1.3 : .35 : .65, 열 간격 1rem. 내부 작업 영역 높이 24rem이며 높이 850px 이하에서는 21rem, 650px 이하에서는 14.8rem으로 조정한다. 아이콘과 문구 크기를 줄이지 않고 폴더 비율과 간격으로 정리한다.

**애니메이션:** 폴더 → Worker A·파일 → Worker B·파일 → Coordinator → A 보고 → B 보고 → ‘메시지로 소통’ → 하단 설명. 단계별 제자리 등장. 창 크기나 폰트가 바뀌면 실제 주체 위치에 맞춰 곡선을 다시 계산한다. 모션 감소 설정에서는 즉시 표시한다.

**발표 노트**
> 같은 워크트리에서 일해도 각 에이전트의 대화 맥락까지 자동으로 합쳐지지는 않습니다. 작업 파일은 폴더에서 다루고, 진행과 결과는 메시지로 공유합니다. 다음 장에서는 작업 공간을 나눠도 이 소통 방식이 같다는 점을 이어 설명합니다.
