# 1인 회사 운영에 유용한 스킬 모음 스토리보드

공통 fastcampus-slide 타이포·배경·푸터·조작을 유지한다. 관계 도식은 HTML/SVG로 제작한다. 2장(표지 + 나만의 스킬 만들기). 2026-09-19 강사 지시로 기존 2~6장(스킬별 소개 5장)을 삭제했다.

## 1. 1인 회사 운영에 유용한 스킬 모음

- 유형: COVER_SCENE. 승인 Part 4 Ch01-01 표지의 공통 헤더·본문 scene·푸터 사용.
- 수강생의 질문: 내 업무에는 어떤 스킬을 골라야 할까?
- 한 문장 답: 맡길 업무와 원하는 결과물에 맞춰 필요한 스킬을 선택한다.
- 제목: 1인 회사 운영에 유용한 스킬 모음. ‘스킬 모음’ brand 강조. 강제 줄바꿈 없음.
- 부제: 핵심 스킬 5종과 최신 트렌딩 스킬을 찾는 방법을 다룹니다. 이 회차의 제공 자료(스킬 5종의 역할·설치·활용법, 최신 트렌딩 스킬 찾는 법 가이드)를 담은 문장형 부제.
- 본문 선언: ‘맡길 업무에 맞춰 / 필요한 스킬 선택’. 두 번째 줄 brand 강조.
- 시각: 아이콘 도식 대신 장면 일러스트. 사람이 책상 위 문서들 가운데 필요한 것을 골라 에이전트 앞 트레이에 담는 장면. 파일은 `/artifacts/part3/_images/ch01-02-repo-and-flow--staging-selection-transparent.png`. Part 3 제작 때 만들었지만 어느 덱에도 쓰이지 않은 이미지다(같은 캐릭터·색). 다른 덱에서 이미 쓴 이미지는 재사용하지 않는다. 새 이미지 생성은 Higgsfield 크레딧 0, Codex 사용 한도 초과로 보류.
- 장면 원장: 사람은 여러 문서 앞에 섬 → 필요한 문서를 집어 트레이에 담음 → 에이전트가 옆에서 받음. 고른 문서는 red 막대, 책상에 남겨둔 문서는 purple 막대라 ‘이번 업무에 필요한 것만 선택’으로 읽힘. 글자 없음.
- 라벨: 없음. 표지에 스킬 이름·Part 목록을 나열하지 않는다.
- 공통 규격: 왼쪽 선언문과 오른쪽 장면 이미지(템플릿의 `.scene__visual` 자리). Ch03-01 및 승인 Part 4와 같은 헤더·본문·푸터 규격.
- 등장: 선언 → 장면 이미지.

## 2. 나만의 스킬 만들기

- 유형: PROCESS_STRIP.
- 핵심: 기존 스킬을 활용할 뿐 아니라, 반복할 작업 방법 자체를 스킬로 제작할 수 있다.
- 배치: 표지 바로 다음. 필요한 스킬을 골라 쓰되, 맞는 스킬이 없으면 직접 만들 수 있다는 흐름으로 연결.
- 근거: docs/curriculum.md Ch03-02의 skill-creator 추천 항목과 제작자 SKILL.md.
- 제목: 나만의 스킬 만들기. ‘스킬 만들기’ 강조.
- 부제: 원하는 작업 방식과 결과물 예시를 스킬로 만듭니다.
- 전달할 자료: 문서 두 개, ‘작업 방식’과 ‘결과물 예시’. gray. 설명 문단 없음.
- 처리: 기존 에이전트 SVG. 이름 ‘에이전트’. 위의 제작용 스킬 배지 ‘skill-creator’. brand.
- 결과물: 폴더 아래 이름 라벨 없음(제목과 중복이라 삭제, 2026-09-19 강사 확정). 폴더 경계 안에 SKILL.md 문서. green. 실제 생성된 파일의 캡처가 아니라 제작 구조를 보여주는 도식.
- 선: 전달할 자료 → 에이전트 → 결과물. 배지는 에이전트가 사용하는 제작 방법을 나타냄.
- 등장: 입력 → 연결선·에이전트·배지 → 연결선 → 스킬 폴더 경계 → 내부 파일.
- 대본: 상품 소개글의 작업 방식과 잘 나온 예시를 재사용할 스킬로 만드는 상황. 에이전트가 제작 주체이고 skill-creator는 그 작업을 돕는 스킬. 시험 적용 후 수정이 필요할 수 있음을 짧게 설명. 소개·추천 범위를 넘어 설치·실습은 하지 않음.
- 검수: 2133×1200·1280×800. 전달할 자료/결과물 명확성, 결과가 일반 회사 문서가 아닌 스킬인지, 문서 접힘 효과 없음, URL·전체 2장 번호 확인.

## 2026-09-19 공통 규격 수정

- 표지부터 마지막 장까지 상단 헤더, 제목·부제, 패딩, 푸터를 같은 공통 규격으로 유지한다. 중앙 제목 전용 표지 스타일은 제거한다.
- 기준: `ch01-01-orchestration-structure.html` 승인본, `ch01-02-goal-task-flow.html` 승인본, 스킬의 `base-template.html`과 골든셋.
- 본문의 제목은 `.heading`, 설명·스킬명·캡션은 `.copy` 규격, 핵심 선언은 `.statement` 규격을 사용한다. 슬라이드별 폰트 축소나 굵기·행간 변경 없음.
- 에이전트는 승인 Part 4 SVG 실루엣과 색을 사용한다. 연결선은 보이는 도형의 중심과 외곽에 맞춘다.
- 기존 슬라이드 개수·순서·주장 유지. 포함 경계와 내부 요소의 등장 순서를 구분한다. 본문 전체 클릭 이동 없음.
- 검수: 2133×1200·1280×800 전 장, 804×512 작은 화면. 공통 헤더 위치·계산된 타이포와 로고를 승인본과 대조한다.

검수 완료: 7장 전체를 2133×1200·1280×800·804×512에서 확인. 본문 잘림·넘침·이미지 이상 없음. 승인 표지와 공통 타이포·헤더·푸터 규격 일치. 기존 대본의 제목·순서·장수 일치.


## 2026-09-19 연결선과 도식 간격

- 가로 연결선은 짧은 SVG 화살표로 통일한다. 빈 가로 공간에 맞춰 선을 늘리지 않는다.
- 화살촉과 선은 같은 굵기와 둥근 끝을 사용한다. 세로 방향도 같은 형태로 표현한다.
- 표지는 문서·에이전트 사이를 고정 간격으로 모은다. 본문은 도식 전체 너비와 에이전트 열을 좁힌다.
- 화살표는 에이전트 그림의 중심에 맞춘다. 라벨을 포함한 컨테이너의 중심으로 잡지 않는다.
- 공통 타이포, 아이콘 크기, 제목·결과 라벨의 세로 여백, 등장 순서와 이동 방식은 유지한다.
