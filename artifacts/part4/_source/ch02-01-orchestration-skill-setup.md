# 오케스트레이션 스킬 설치하기 — 도입

사용 위치: 오케스트레이션 스킬 설치 실습 직전. 아래 한 장 뒤에 실제 설치 화면으로 넘어간다. 설치 절차 전체의 슬라이드 덱이 아니다.

## 도입 슬라이드

- 제목: 일을 나누고, 넘기는 흐름까지
- 부제: 사람이 매번 전달하던 일을 에이전트의 협업 흐름으로 구성합니다.
- 기존 2단 비교 레이아웃 유지.
- 왼쪽: 사람이 직접 넘기면 / 멀티 에이전트 과도기 / 에이전트가 여럿이어도, 자료 전달은 사람 몫
- 오른쪽: 협업 흐름으로 연결하면 / 에이전트 오케스트레이션의 시대 / 목표 하나로 일을 나누고, 결과를 다음 담당자에게 전달
- 오른쪽 시각: 여러 에이전트 사이의 결과 전달 화살표와 반려 시 돌아오는 점선.
- Orca 이름·로고·제품 기능 설명을 넣지 않는다. 사람의 수동 전달과 오케스트레이션의 차이에 집중한다.
