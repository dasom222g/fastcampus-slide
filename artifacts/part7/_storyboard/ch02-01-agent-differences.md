| 2 | 같은 요청, 다른 결과 | 같은 상세페이지 작업에서 나온 두 시안의 표현 차이를 비교합니다. |

| 6 | 내 업무의 선택 기준 | 결과가 목적을 달성했는지 확인하고 정확성과 수정 부담까지 평가합니다. |

## 최종 메시지

내 업무의 목적·필수 조건은 명확히 주되, 해결 방법은 모델에게 맡긴다. 모델이 스스로 판단해 만든 결과의 품질을 비교해 내 업무에 가장 잘 맞는 모델을 선택한다.

## 장별 구성

| 장 | 제목 | 헤드메시지 · 시각화 |
|---|---|---|
| 1 | 같은 작업도 에이전트에 따라 결과가 갈린다 | 확정 표지 유지. 모델 성능 순위보다 내 업무에서 직접 비교한 결과로 선택. |
| 2 | 같은 요청, 다른 결과 | 실제 디자인 시안은 차이를 체감하는 도입 사례로만 사용. 삭제 승인된 하단 문구 복원 금지. |
| 3 | 모델의 판단 | 목적·필수 조건 → 모델의 판단 → 해결 방법·결과의 흐름. 사람이 지정하지 않은 선택이 결과로 드러남. |
| 4 | 목적과 방법의 구분 | 목적·자료·필수 조건은 공통으로 명확하게, 해결 절차·정보 구성·표현은 모델이 선택. 열린 두 열. |
| 5 | 같은 업무로 비교 | 동일한 실제 업무를 서로 다른 모델에게 맡기고 독립된 결과를 비교. 요청 문서 → 모델 A/B → 결과 A/B, 중앙 도식과 하단 정의. |
| 6 | 내 업무의 선택 기준 | 목적 달성·정확성·수정 부담으로 결과를 평가. 단순한 취향이나 보기 좋은 정도에 그치지 않음. |
| 7 | 내 업무의 주력 모델 | 대표 작업을 여러 번 비교해 실제로 쓰기 좋은 모델 선택. 같은 요청을 남겨 새 모델에도 재사용. 열린 세 단계. |

## 범위와 검수

3~7장을 일반 업무의 모델 선택이라는 최신 사용자 지시로 개편한다. 모든 해결 절차를 상세히 지정해 동일 결과만 재현하도록 만드는 설명은 배제한다. 1~2장 보존. 강의 제목·표지 확정 문구·7장 장수 유지. 대본은 변경하지 않는다.
