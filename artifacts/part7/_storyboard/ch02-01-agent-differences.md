# 같은 작업도 에이전트에 따라 결과가 갈린다 스토리보드

출력: `artifacts/part7/outputs/ch02-01-agent-differences.html`
총 슬라이드: 7장

## 핵심 메시지

남의 성능 순위를 따르기보다 내 업무에 같은 조건으로 요청하고, 실제 결과의 만족도로 모델을 선택한다.

| 장 | 제목 | 핵심과 표현 |
|---|---|---|
| 1 | 같은 작업도 에이전트에 따라 결과가 갈린다 | 기존 표지 유지 |
| 2 | 같은 요청, 다른 결과 | 기존 실제 디자인 결과 비교 유지 |
| 3 | 왜 갈리나 | 기존 해석의 차이 설명 유지 |
| 4 | 고정 조건과 자유도 | 같은 목적·자료·조건·완료 기준과 자유로운 구성·문체·시각 표현·해결 방식을 열린 두 열로 구분. 화살표 대응 없음 |
| 5 | 내가 쓸 결과의 기준 | 조건 충족·표현 적합·수정 부담. 문서 검사·표현·수정의 시각 요소와 짧은 질문을 열린 세 열에 배치 |
| 6 | 목적에 따라 다른 선택 | 핵심 압축형·배경 설명형 두 결과를, 빠른 보고와 자세한 설명이라는 서로 다른 목적에서 선택하는 비교표. 특정 모델 성능으로 일반화하지 않음 |
| 7 | 내 업무에 맞는 모델 | 내 작업으로 요청·직접 써 보고 선택·새 모델로 재비교. 번호와 그림으로 세 행동을 구분 |

## 동작과 범위

- 4장은 고정 조건, 자유도 순으로 등장. 5~7장은 각 관점·행동을 순차 등장시킨다.
- 1~3장 HTML, 클립명, 커리큘럼, 다른 덱은 보존한다.
- 하네스는 실행 도구, 모델은 그 안에서 쓰는 AI로 구분한다. 다른 하네스 간 결과 비교를 모델만의 성능 측정으로 단정하지 않는다.
- 새 이미지 생성 없이 기존 템플릿의 열린 비교·3열·문서 표현과 인라인 SVG를 사용한다.
