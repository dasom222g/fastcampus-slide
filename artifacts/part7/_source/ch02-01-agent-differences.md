# Ch02-01. 같은 작업도 에이전트에 따라 결과가 갈린다

제작 목표: 같은 조건에서 자유롭게 만든 결과를 직접 사용·비교하며, 내 업무와 만족도에 맞는 모델을 스스로 선택한다.

## 사실과 제작 범위

- 두 시안은 실제 실행 결과 캡처다. 어느 하네스가 더 낫다는 결론은 내지 않는다.
- 결과가 갈리는 이유를 모델 성능 순위로 설명하지 않는다. 지침이 비워 둔 자리를 각자 해석한 것이다.
- 4장 이후는 특정 프로젝트를 벗어나 조건 충족·표현 적합·수정 부담을 기준으로 내 업무에서 비교한다.
- 선택 결과를 정답으로 고정하지 않는다. 실행할 때마다 달라질 수 있다.

### 4. 고정 조건과 자유도

- 고정: 목적, 입력 자료, 필수 조건, 완료 기준.
- 자유: 구성, 문체, 시각 표현, 해결 방식. 업무상 이미 정해진 사항은 고정 조건으로 둔다.
- 열린 두 열로 구분하고 항목 사이를 화살표로 대응시키지 않는다.

### 5. 내가 쓸 결과의 기준

- 조건 충족: 요청한 일을 빠짐없이 했는가.
- 표현 적합: 내가 원하는 구성과 말투인가.
- 수정 부담: 바로 쓰려면 얼마나 고쳐야 하나.

### 6. 목적에 따라 다른 선택

- 동일하게 조건을 충족한 핵심 압축형·배경 설명형 결과를 비교한다.
- 빠른 보고와 자세한 설명이라는 목적에 따라 선택이 달라지는 구조다.
- 특정 모델의 우열이나 항상 적용되는 정답으로 쓰지 않는다.

### 7. 내 업무에 맞는 모델

- 내가 자주 하는 작업으로 같은 조건의 요청을 남긴다.
- 직접 사용하며 만족도와 수정 부담으로 선택한다.
- 새 모델도 같은 작업으로 비교한다. 중요한 일은 여러 사례에서 확인한다.
- 다른 하네스를 함께 비교했다면 모델만의 성능 차이라고 단정하지 않는다.
