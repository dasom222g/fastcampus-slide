## 1. 팀을 굴리면 토큰이 몇 배로 드는가

- 수강생의 질문: 왜 팀을 실행하면 토큰이 더 드는가?

- 패턴: COVER_SCENE
- 시각 구조: 왼쪽은 「멀티에이전트 / 함께 늘어나는 토큰」, 오른쪽은 에이전트 팀과 금화·지폐를 함께 보여주는 투명 배경 생성 이미지. 제목의 「토큰이 몇 배」 전체를 키컬러로 강조한다.
- 애니메이션: 요소 순서대로 등장. 개괄은 맥락 전달 → 실행·조율 → 재작업, 마지막은 유지할 작업 완료 후 줄일 중복.

## 2. 멀티에이전트의 토큰 사용량

- 시각 구조: 원본의 일반 채팅 1×, 에이전트 약 4×, 멀티에이전트 약 15× 막대와 출처 보존. 고정 배수·요금 배수가 아님을 명시.
- 애니메이션: 요소 순서대로 등장. 개괄은 맥락 전달 → 실행·조율 → 재작업, 마지막은 유지할 작업 완료 후 줄일 중복.
