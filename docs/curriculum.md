# 상세 커리큘럼

전체 10개 파트 · 72클립 · 약 12시간. **파트·챕터·클립의 번호와 제목이 여기서 확정된다.**

## 이 문서가 정하는 것 / 정하지 않는 것

| | 어디에 |
|---|---|
| 파트·챕터·클립의 번호·제목·길이 | **이 문서** |
| 어떤 클립에 슬라이드를 몇 장 만들지 | `artifacts/<part>/_source/<clip>.md` (클립별 슬라이드 소스) |
| 클립 안에서 무엇을 어떤 순서로 말할지 | `artifacts/<part>/_source/<clip>.md` |
| 강의 톤·청중·용어·강조점 | `docs/course-brief.md` |

## 파일명 규칙

클립 하나가 슬라이드 덱 하나이고, 파일명은 **클립 번호 + 영문 슬러그**다.

```
Part 2 › Ch02-01. 설치 전 준비물과 환경 체크
  → artifacts/part2/ch02-01-setup-prep.html
  → 공개 주소 /part2/ch02-01-setup-prep
```

- 파트 폴더는 `part1` … `part10`으로 고정. 파트 제목은 이 문서에서만 관리한다
- 클립 번호는 이 문서의 번호를 그대로 쓴다 (`Ch02-01` → `ch02-01`)
- 슬러그는 케밥케이스 소문자, 3단어 이내
- 스토리보드·피드백·이미지는 **확장자만 빼고 같은 이름**을 쓴다

**모든 클립에 슬라이드를 만들지 않는다.** 어떤 클립이 슬라이드를 갖는지는 클립 소스 frontmatter의 `슬라이드: N장`이 정한다 — `슬라이드: 없음`이면 만들지 않는다.
소스가 아직 없는 클립도 만들지 않는다.
