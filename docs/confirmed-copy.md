# 확정 문구

강사가 확정한 이론자료에서 그대로 옮긴 표현이다. **여기 있는 말은 바꾸지 않는다.**
내 스토리보드의 표현과 어긋나면 **이 문서가 이긴다.**

> 이 PDF는 **내용 파악용**이다. 디자인·레이아웃은 참고하지 않는다.

## 강의 목표

> 스스로 일을 나누고 협업하는 **AI 팀 설계·운영 능력** 기르기

- 목표 하나로 굴러가는 AI 팀을 설계한다
- 실무에 바로 써먹는 멀티에이전트 패턴 4가지를 익힌다
- 도구가 바뀌어도 흔들리지 않는 기본기를 만든다

## 에이전트의 진화 — 3단계 확정 명칭

| 단계 | **확정 명칭** | 확정 설명 |
|---|---|---|
| 1 | **에이전트의 탄생** | 채팅창에 갇혀있던 AI가 내 파일을 열고 직접 작업하기 시작합니다 |
| 2 | **멀티 에이전트 과도기** | 에이전트는 늘었는데 일을 넘겨주는 건 여전히 제 몫입니다 |
| 3 | **에이전트 오케스트레이션의 시대** | 목표 하나만 던지면 알아서 일을 나누고 협업해 결과를 만듭니다 |

**2·3단계 이름을 줄여 쓰지 않는다.** `멀티 에이전트`(X) → `멀티 에이전트 과도기`(O),
`오케스트레이션`(X) → `에이전트 오케스트레이션의 시대`(O).
`과도기`와 `시대`가 이 블록의 온도를 만든다.

## 이 강의가 만드는 것

> **'나처럼 일하는'이 아닌 '나 대신 일하는'**

| 나처럼 일하는 에이전트 | 나 대신 일하는 에이전트 |
|---|---|
| 내 말투와 판단 기준을 안다 | **일을 나누고 넘기는 순서를 안다** |
| 프롬프트를 잘 쓰면 하나로도 된다 | 목표만 주면 나누고 실행하고 결과를 낸다 |
| **내가 없으면 멈춘다** | 내가 자리를 비워도 굴러간다 |

## 프로젝트 4개 — 확정 명칭

| # | **확정 명칭** | 확정 설명 |
|---|---|---|
| 01 | **판매 아이템 기획서** | 시장조사부터 아이템 후보 도출, 기획서까지 파이프라인으로 한 번에 돌립니다 |
| 02 | **클라이언트 제안서·견적서** | 작성하는 에이전트와 검증하는 에이전트를 따로 두고 기준을 통과할 때까지 돌려서 최적화된 결과물을 만듭니다 |
| 03 | **프로모션 랜딩페이지** | 두 에이전트에게 동시에 동일한 작업을 줘서 나온 디자인 시안 중 Best를 고릅니다 |
| 04 | **블로그·카드뉴스·스레드** | 소재 하나를 가지고 세 에이전트에게 요청해 플랫폼별 결과물을 매일 뽑습니다 |

## 멀티에이전트 패턴 4가지 — 확정 명칭·정의·매핑

> 프로젝트 4개로 멀티에이전트 패턴을 익힙니다

| **확정 명칭** | 확정 정의 | 프로젝트 |
|---|---|---|
| **순차 파이프라인** | 선행 에이전트가 결과물을 후행 에이전트로 넘기는 구조 | 01. 판매 아이템 기획서 |
| **교차 검증** | 생성과 평가를 서로 다른 에이전트에 분리하는 구조 | 02. 클라이언트 제안서·견적서 |
| **병렬 실행** | 동일 요청을 여러 에이전트에 동시 배분하는 구조 | 03. 프로모션 랜딩페이지 |
| **R&R 분배** | 하나의 소재를 역할별로 나눠 확장하는 구조 | 04. 블로그·카드뉴스·스레드 |

- `병렬 작업`(X) → **`병렬 실행`**(O)
- `순차 처리`(X) → **`순차 파이프라인`**(O)
- 패턴 순서는 **순차 → 교차 검증 → 병렬 실행 → R&R 분배**이고 프로젝트 번호와 1:1로 맞는다

### Ch01-01에서 패턴 이름을 쓴다

**확정 자료는 Ch01-01에서 패턴 4가지의 이름과 정의를 모두 노출한다.**
클립 소스에 적힌 "패턴 이름이나 설명은 하지 않는다"는 확정 자료와 어긋나므로 **확정 자료를 따른다.**
다만 깊은 설명은 Part 5 Ch01-01의 몫이고, 여기서는 이름 + 한 줄 정의 + 프로젝트 매핑까지다.

## 이 강의가 강조하는 것 (문서 전체에서 반복되는 축)

1. **사람이 붙어 있어야 하는가** — 이것 하나가 '나처럼'과 '나 대신'을 가른다
2. **일을 나누고 넘기는 순서** — 프롬프트가 아니라 순서와 구조가 주제다
3. **도구가 바뀌어도 남는 것** — 패턴은 Orca 전용 개념이 아니다
4. **결과물이 실물로 남는다** — 추상적 역량이 아니라 프로젝트 4개가 손에 남는다
